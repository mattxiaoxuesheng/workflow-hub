# 图片自动压缩与预览

前端支持上传不超过 10MB（10 × 1024² 字节）、4000万像素的静态 JPG、PNG、WebP。原图按内容哈希保存，原工作稿和历史版本继续引用原图。上传时生成独立微信正文、封面副本，分别不超过 1,000,000、2,000,000 字节。

副本修正 EXIF 拍摄方向，最长边限制为 2560 像素。优先保留满足限制的原 JPEG/PNG 或生成无损 PNG；需要进一步缩小时转换 JPEG，逐步调整质量、必要时缩小尺寸。透明图转 JPEG 时使用白底并明确提示。GIF、动态 WebP、SVG、HEIC 不在本轮支持范围。

素材库中的“查看微信图片副本 / 原图对比”和“微信发送预览”提供原图/副本对比，显示像素尺寸和文件大小。点击图片可在新标签页打开大图检查小字、细节。自动校验格式和大小不能保证视觉清晰度，须人工确认预览。最终 HTML 使用微信上传返回的图片地址；本地对比显示实际上传的相同副本字节。确认发送时不会再次压缩或上传图片。

新预览在数据库保存实际上传副本清单。旧版已经准备好的预览保留原 HTML 和封面媒体 ID，不把新生成的副本宣称为原发送产物；页面提示保存新版本后再生成压缩预览。SQLite 仅添加字段，保留原有数据。

副本缓存位于素材目录 `.publication-v1`，原图不被覆盖。缓存可以根据原图重建，备份仍保留原图和数据库。压缩算法版本应保持稳定；后续算法变更需使用新的缓存版本，避免影响已经确认的副本。

部署新镜像后功能才在线上生效。此修改不包含独立跨文章共享素材库，也未执行真实微信公众号发送。
