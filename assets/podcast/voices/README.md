# 克隆参考声音

这里用于放置自己的、或获得许可的短参考录音，非完整播客成品。每人 3–30 秒，推荐先录制约 10 秒清晰干声，支持 wav/mp3/m4a/flac/ogg，最多 10 MB。

参考录音默认被 .gitignore 忽略。本仓库公开：若选择将录音提交到这里，文件会公开且保留在 Git 历史中。仅在明确愿意公开时，在 GitHub 网页上传或使用 git add -f 指定文件；程序不会替你上传。不要放私密录音。

不希望公开时，在本机 Docker 的同一路径挂载文件运行；当前 GitHub 工作流尚未接入私有录音下载。HF_TOKEN 只提供 HF 身份认证，不能替代参考录音。

参考文字必须与录音内容一致，写在文稿 reference_text；它也会包含在节目元数据中。声音克隆需要把参考录音发送到 Qwen 官方 Space。

完整配置见 [HF_SPACE.md](../../../workflows/podcast/HF_SPACE.md)。
